# iOS 1.2.1 配套后台更新

此 app.py 基于 2026-11-05「数字朗读修复_后台网页版」包，保留数字朗读语言选择及翻译语种校验。若服务器之后改过 app.py，请先合并差异。

1. 备份服务器现有 app.py。
2. 用本目录 app.py 覆盖服务器后台同名文件，保留 data/、配置、数据库以及所有其他文件。
3. 按原部署方式重启后台。无需修改服务商密钥或用户数据。
4. 更新 iOS 后打开逐句学习，点击「重新生成学习内容和音标」。旧学习记录仍可打开，旧数据不会自动发起付费生成。
5. 分别在中译老、老译中朗读数字 20，确认语言正确；检查整句和关键词 IPA，切换页面后返回确认本地缓存可读。

POST /study 新增可选布尔字段 phonetics。true 时要求并返回 pairs[].ipa 与 pairs[].words[].ipa；不传时保留旧响应结构。IPA 由现有 daily 模型生成，无法可靠标注时返回空字符串，不能保证语言学准确度。

POST /tts 保持 language=lo/zh/auto；iOS 依据目标语言明确传参。新版本仅重建纯数字或数字标点音频缓存，其他离线音频保留。

本目录是服务端配套文件，不打入 iOS App。执行测试：python3 -m unittest discover -s backend/tests -v。

已移除历史版本内置的语音密钥和强制迁移配置代码，保留现有 config.json 配置。旧包包含的密钥应在对应服务商控制台轮换。
